# Mi portfolio

¡Hola! Este es mi espacio para compartir un poco sobre mí, mi experiencia y algunos proyectos que he hecho. También quiero poder incluirlo en mi resume para que sea fácil conocer mi trabajo.

## ¿Qué archivos hay aquí?

- `index.html` tiene el contenido: mi información, experiencia, proyectos y formas de contacto.
- `styles.css` hace que la página tenga su diseño y se vea bien en el celular.
- `script.js` se encarga de algunas funciones, como cambiar el idioma y los colores.

No necesito instalar programas adicionales para abrirlo.

## ¿Cómo lo veo en mi computadora?

Abro el archivo `index.html` con mi navegador. Si hago cambios, guardo el archivo y vuelvo a cargar la página para verlos.

## ¿Cómo lo publico en GitHub?

Cuando esté listo para compartirlo:

1. Subo estos archivos a mi repositorio de GitHub.
2. En ese repositorio, voy a **Settings → Pages**.
3. En **Build and deployment**, elijo **Deploy from a branch**.
4. Selecciono la rama `main` y la carpeta `/(root)`, y guardo.
5. Espero a que GitHub Pages publique la página. Allí mismo aparecerá el enlace que puedo añadir a mi resume.
